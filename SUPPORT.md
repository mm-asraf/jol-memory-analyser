# Support

## Where to get help

| Channel | When to use |
|---------|-------------|
| [GitHub Discussions](https://github.com/mm-asraf/jol-memory-analyser/discussions) | Usage questions, ideas, general feedback |
| [GitHub Issues](https://github.com/mm-asraf/jol-memory-analyser/issues) | Confirmed bugs and feature requests |
| [SECURITY.md](SECURITY.md) | Undisclosed security vulnerabilities |

Please search existing issues and discussions before opening a new one.

## Before opening an issue

- Confirm you are on the latest version from [Maven Central](https://central.sonatype.com/artifact/io.github.mm-asraf/jol-memory-analyser).
- Include your Java version (`java -version`), OS, and the full stack trace or output if applicable.
