# Security policy

## Supported versions

We aim to support the **latest release** published on [Maven Central](https://central.sonatype.com/artifact/io.github.mm-asraf/jol-memory-analyser) for this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for undisclosed security vulnerabilities.

Instead:

1. Use **[GitHub Security Advisories](https://github.com/mm-asraf/jol-memory-analyser/security/advisories)** for this repository (**Report a vulnerability**), **or**
2. Email **mahboob.webdev.asraf@gmail.com** with a clear subject line (e.g. `[SECURITY] jol-memory-analyser`).

Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept, if possible
- Affected versions or commits, if known

We will acknowledge receipt as soon as we can and coordinate a fix and disclosure timeline.

## After reporting

We treat reports seriously. Depending on severity, we may prepare a patch release and publish a GitHub Security Advisory when appropriate.
